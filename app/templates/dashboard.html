ECDSA

Elliptic Curve Digital Signature Algorithm. Used to create and verify digital signatures, allowing applications to prove that data was signed by the correct private key.

ECDH

Elliptic Curve Diffie-Hellman. Allows two parties to independently derive the same shared secret without directly sending the secret across the network.

/api/v1/ecdh/derive

Testing Guide

Basic workflow for testing the Security API

1

Generate an ECC Key Pair

Open Swagger and execute POST /api/v1/keys/generate. Save the returned key_id.

2

Test ECDSA Signing

Send a message together with the generated key ID to /api/v1/ecdsa/sign. The API returns an ECDSA signature.

3

Verify the Signature

Send the original message and signature to /api/v1/ecdsa/verify. A correct signature should return "valid": true.

4

Test Tampering

Change the original message but keep the old signature. Verification should return "valid": false. This demonstrates data integrity.

5

Test ECDH

Generate two ECC keys and use /api/v1/ecdh/derive. Both parties should derive the same shared secret.

6

Test Hashing

Send data to /api/v1/hash/sha256. The same input should always produce the same SHA-256 hash.
